Working with Positions

Sticky

This is an example of an element with a sticky position. Its position is based on the user's scroll position.

The top 0 property positions the absolute box directly at the top edge of its containing element.

Relative

This is an example of an element with a relative position. It can move around a little, depending on the viewport, but it is in a position relative to itself.

The top 90px property moves the absolute box 90 pixels down from the top of its containing element. The left 30px property moves the box 30 pixels to the right from the left edge.

Fixed

This is an example of an element with a fixed position. Its position is relative to the viewport.

The top 90px property moves the absolute box 90 pixels down from the top of its containing element. The right 10px property places the box 10 pixels away from the right edge of its containing element.

Absolute

This is an example of an element with an absolute position. It is similar to the fixed position; however, it is positioned relative to the closest parent element.

I used values of 0 for the bottom and right properties, causing the box to the go directly to the bottom and directly to the right.
